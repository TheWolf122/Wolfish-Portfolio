# **FOUNDATIONAL PROGRAMMING PROJECTS**
### Anna Tuite | Computer Science Portfolio

## OVERVIEW

This collection brings together small projects that document my foundation in
computer science and software development. Projects such as basic HTML pages
and calculator logic show how I translate an idea into working code, organize
information, and solve problems through clear, repeatable steps.

Each project has a focused scope, making the underlying concepts easy to
review. Together, they provide a starting point for my continued work in
application development and cybersecurity.

## PROJECT FOCUS

Basic HTML
These projects demonstrate an understanding of how HTML elements structure
web content and how a page's organization affects the reader's experience.
They establish a foundation for building more interactive web applications.

Calculator Logic
These projects demonstrate the use of variables, arithmetic operations, and
conditional logic to turn inputs into results. They show how a familiar task
can be broken into smaller computational steps and implemented in code.

Other Foundational Exercises
Additional small projects explore core programming concepts and provide
opportunities to practice applying them to different problems.

## SKILLS AND FOUNDATION

- Problem decomposition: Breaking a task into manageable steps and translating
  those steps into program behavior.
- Programming logic: Working with data, expressions, and decisions to produce
  an intended result.
- Web fundamentals: Understanding the role of HTML in structuring and
  presenting information.
- Attention to correctness: Considering how inputs, calculations, and program
  flow affect the accuracy of an output.
- Technical communication: Making the purpose and logic of a project
  understandable to someone reviewing the code.
- Continued learning: Building on focused exercises as I take on more complex
  development challenges.

## CONNECTION TO MY PROFESSIONAL GOALS

My interests include software development and cybersecurity. Understanding
how applications process information and respond to user input is a useful
foundation for both fields. These projects support that foundation while
giving me opportunities to strengthen my coding and problem-solving skills.

As my portfolio grows, I aim to apply these fundamentals to projects with
more demanding requirements, including input validation, error handling,
